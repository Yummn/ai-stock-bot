# StockLab 3.0 / 行情实验室

旧研究区说明。当前默认启动方式见 [项目首页](../README.md)；以下端口、界面和启动说明属于 3.0，不适用于 4.0 主界面。

本机运行的行情研究、历史回测与模拟账户。新版网页不连接券商、不提交实盘订单。

## 启动

本机依赖和网页已经安装、构建。双击 `run_web.bat`，打开 <http://127.0.0.1:8768/>。

更换端口：

```powershell
.\run_web.bat 8770
```

已启动同一端口时无需重复启动。关闭浏览器不会停止计算；关闭服务或电脑会中断，学习任务可以手动继续。

## 三个工作区

| 工作区 | 内容 |
| --- | --- |
| 账户 | 当前资产、持仓、决策、可切换行情、模拟运行和手动模拟 |
| 方案 | 选择决策方法与风格、匹配当前参数的历史证据、独立参数编辑器、保存并启用 |
| 实验 | 跨年评估、单段回测、参数优化、验收年份、可恢复任务与完整历史 |

**保存并启用**会保存所有模型、所有档位、标签和风控。编辑草稿先进入实验，模拟账户只使用服务端启用方案。运行任务使用提交时的配置快照，之后修改参数不会改变已经开始的实验。

方案页的“交易时怎样选档”可选择固定档位、根据价格走势，或在机器学习模式下根据近 60 个交易日的模拟净收益选档。同一个历史表现栏随选择切换，只匹配当前方式的评估记录；记录不足时回退价格走势。三个月方式会额外训练三档影子模型，尤其神经网络运行可能明显变慢。切换选项只修改草稿，仍需“保存并启用”才影响模拟账户。实际对照见 [选档方式测试](docs/PROFILE_SELECTION_TEST_2026-09-28.md)。

固定方式显示四个档位按钮；自动方式不突出手选档位，而按 ETF 展示选中的档位、原因和日期。价格走势从缓存行情即时计算；三个月成绩只显示与当前方案匹配的最近一次模拟结果，尚未运行时会明确提示，不借用旧方案的结果。

**恢复默认基线**独立保存在数据库中，不随普通保存或参数优化改变。“数据与维护”显示保存日期，并可将当前已启用参数重新设为默认；未保存草稿不会计入。参数编辑器的“恢复这一组默认”会读取最新基线，只修改当前组的草稿，之后仍需保存并启用。没有自定义基线的安装继续使用初始内置参数。

“数据与维护”集中管理行情覆盖、交易与训练范围、年度标签、方案文件和远程访问。详细设计取舍、新增能力与验证见 [3.0 升级说明](docs/WORKBENCH_V3.md)。

本地规则、AI / Codex、RandomForest、HistGradientBoosting、XGBoost、PyTorch MLP、1D-CNN 均已保留。机器学习支持二分类 / 五分类；XGBoost、MLP、CNN 可选 CUDA。神经网络采用时间顺序验证早停与小批次训练。

AI 使用本机现有 `.env` 和登录态；提示词按档独立。每次 AI 判断获得五种机器学习模型的激进、均衡、保守档共 15 组参考，可在决策中展开查看。自定义档不进入参考。AI 全年测试关闭，只开放短期验证。全部参考不可用时安全观望，不把本地信号伪装成模型预测。

## 数据与成交口径

- Yahoo OHLC / adjusted 优先，AKShare ETF 日线备用；实际来源和覆盖日期可查。网络不可用且缓存不能覆盖请求时明确失败。
- 训练窗口 1 / 3 / 5 / 10 年仅影响训练区间，**不改变测试年份或价格曲线**。
- 自己训练自己 → 按行情分类 → 全部混合 → 本地规则，逐级回退，诊断中显示实际样本和训练标的。
- 训练标签必须完整结束在测试开始之前。完整年度标签仅用于已经结束的历史年份；当日切档只读取当时已经出现的行情。
- 收盘形成信号，下一交易日原始开盘价成交；计入手续费、滑点和份数 / 仓位限制。止损止盈在日线开盘检查，并非盘中触发模型。
- 持有基准为交易池等金额买入持有，采用相同成交成本。分红再投资、停牌细则、涨跌停无法成交和完整券商规则尚未模拟，结果是研究估算。

模型概率不保证盈利；五分类中上涨概率加半个中性概率是“机会分”，不是严格的上涨概率。反复搜索同一批年份仍会产生选择过拟合，需要额外保留未参与搜索的验证区间。

## 本机保存与旧版

新版数据目录：`data/v3/`，数据库 `stocklab.sqlite3`，预测缓存 `predictions/`。

首次启动将 `data/v2/stocklab.sqlite3` 中的配置、模拟账户、行情和实验复制到新目录，不修改原数据；已存在新版数据库时不重复导入。无 V2 数据时导入兼容的旧设置、模拟账户和收盘缓存。旧结果不按新评分口径重写。

旧页面：`run_web_legacy.bat`，默认端口 8766。旧 CLI / 券商代码仍在，但与新版模拟网页隔离。旧说明见 [Legacy README](docs/LEGACY_README.md)。

## 远程演示

本机默认无需登录。经 Cloudflare Tunnel 或局域网访问时默认只读，运行任务、修改设置和模拟买卖需要管理口令。

本机“数据与维护”可查看口令；远程页面可解锁管理权限，有效期 7 天。口令在 `data/v3/access-key.txt`，不要上传 GitHub、公开分享或放进演示版压缩包。

现有隧道若仍指向 8765，不会自动切换到新版。新版正式入口为 8768；公网切换需将隧道本地目标更新为 `http://127.0.0.1:8768`。

此机制适合个人使用 / 小型演示，不是多人账户系统。公网部署仍应使用 HTTPS、可信反向代理以及更完善的权限、日志与限流方案。

## 开发与验证

Python 3.10+，Node.js 20.19+ 或 22.12+。

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pip install -e ".[test]"
cd frontend
npm.cmd ci
npm.cmd run build
```

回到项目根目录：

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe scripts/launch_workbench.py --port 8768
```

生产网页随 Python 包分发，不需要运行 Node 服务。前端源码在 `frontend/src/`；后端分层在 `src/ai_stock_bot/v2/`。接口使用严格配置模型、版本冲突检测、SQLite WAL；耗时任务由独立子进程执行，网页不会持有训练锁。

详见 [V2 实现与验证](docs/STOCKLAB_V2.md) 和 [后续重构路线](docs/REFACTOR_PLAN.md)。
