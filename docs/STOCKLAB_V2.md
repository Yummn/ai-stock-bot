# V2 初版实现

## 产品取舍

保留调试能力，但把日常查看、历史测试、自动学习和参数编辑分开。
桌面使用侧栏与宽屏布局，手机使用四项底栏；手机的三档学习结果逐档切换，桌面并排显示。
训练诊断、模型参数、交易记录、年度标签与建议参数默认折叠。表格只在自身容器横向滚动，不让整页越界。

当前保存方案为本地均衡入门；迁移的旧选择另存为“旧版迁移方案”。各模型兼容的旧参数仍然保留，没有重置旧数据库。

## 模块边界

| 文件 | 唯一职责 |
| --- | --- |
| schema.py | 配置、参数目录、合法值与旧配置兼容 |
| store.py | 短事务持久化、配置版本、任务、候选与历史数据 |
| market.py | 行情适配、OHLC 校验、覆盖信息、年度标签 |
| features.py | 只依赖已知行情的特征与截断标签 |
| estimators.py | 五种模型、时间验证、CPU / CUDA、原子预测缓存 |
| strategies.py | 本地 / ML / AI 信号及已知行情校准 |
| execution.py | 模拟账户、可卖数量、金额仓位和成本 |
| backtest.py | 固定日历、下一日成交、持有基准、结果诊断 |
| paper.py | 最近已收盘行情的单轮模拟与重复运行保护 |
| learning.py | 三档候选、评分、各档冠军与断点继续 |
| jobs.py | 子进程隔离、心跳、停止与异常退出报告 |
| api.py | 结构化接口、远程只读 / 管理认证、静态资源 |

前端 Vue + TypeScript，图表 ECharts 按需加载。页面不是另一份参数默认值来源，默认值与模型参数目录来自后端。

## 必须维持的约束

1. 训练开始 / 截止和测试起止相互独立；数据不足不偷偷改测试区间。
2. 标签的未来结束点在训练截止之前，年度标签不能来自当时尚未结束的一年。
3. 信号只使用收盘已知数据，成交不得使用同日收盘价。
4. 当日亏损限制只阻止新增买入，不阻止止损卖出。
5. 模型 / 档位分别存储；提交后参数快照冻结；多设备过期保存返回 409，不覆盖新版本。
6. 年份失败的候选不能成为推荐冠军，默认候选不额外加分或扣分。
7. 已完成候选即时入库，停止后可继续；没有计算硬超时；原生计算崩溃不得关闭网页服务。
8. 任务轮询不读取完整结果，仅结果版本变化时加载详情；候选分页读取，冠军通过数据库查询，持续学习不累积整份候选配置在内存中。
9. 公共展示不等于公共管理，远程写操作需要认证，跨站写请求拒绝。

## 验证记录

本次验证使用真实行情与合成测试行情两类，严格区分研究结果和代码正确性检查。

- 后端自动测试涵盖五模型 CPU、五分类概率映射、未来数据隔离、1/3/5/10 年窗口、下一日开盘成交、T+1、风控退出、配置分档保存、版本冲突、只读迁移、后台响应与停止、AI 适配 / 回退计数、行情时效、学习分页 / 应用与远程访问认证。
- TypeScript 检查和 Vite 生产构建通过。
- 真实 RF 2025 年测试日期 2025-01-02 至 2025-12-31，共 242 个交易日。买卖标注验证方案发生 12 笔交易。此为功能验证，不是正式调优结果。
- RF 三档各 3 候选验证 2021–2025，9 个候选共 45 次年度计算完整完成，三档均有独立结果。
- XGBoost 和 1D-CNN 的短期真实数据任务均报告 CUDA；CNN 使用 2 轮小规模训练，仅检查 GPU 接入。
- 20 个 ETF 历史更新完成；历史最早日期由上市日期及请求范围决定，未补造缺失年份。最近缓存行情为 2026-09-24。
- 持续学习运行到 40 轮 / 353 个候选，停止后继续新增候选成功；结果接口约 44 KB，不包含全部候选参数，完整历史可分页读取。
- 桌面与手机检查导航、结果恢复、参数保存、局部表格滚动与图表实际像素。AI 外部调用未执行，仅做适配层模拟响应测试，不消耗 AI 调用额度。

## 初版边界

- 先统一日线口径；旧分钟慢速回测、定时模拟巡检没有迁入新版。持续自动学习已保留。
- 参数搜索仍以所选年份评分，尚未实现独立保留集 / 完整嵌套走步验证，搜索结果不能当作未来收益保证。
- 当前缓存保存的是预测与诊断，不是可导出部署的模型权重。
- 神经网络支持 CUDA 小批次，但尚无混合精度；原生 CUDA 崩溃记录为任务失败，可切 CPU 重试，并不保证自动恢复 GPU 故障。
- 数据源修订、复权变化可能使后来重新下载的研究数据发生变化；每次结果记录数据指纹，但未冻结完整行情快照文件。
- 不含交易所 / 券商级撮合，不支持实盘、做空、期货对冲；公共口令不是多用户权限系统。

后续新增能力应遵守模块边界与上述回归测试，避免再次把所有状态与计算堆入一个页面或处理器。
