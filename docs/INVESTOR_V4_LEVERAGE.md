# 风险倍数：研究情景与实盘边界

当前投资计划和实盘准备页均为 1x。验证页的 2x/3x 是从已保存的历史组合曲线派生的只读情景，不修改模型训练、模拟账户、投资计划或真实订单。换基础组合不需要重新运行五年模型，但修改投资计划的资金、标的或策略参数后，须先得到匹配的新验证报告。

## 计算口径

基础组合在第 `t` 个交易日的净值收益为 `r_t = E_t / E_(t-1) - 1`，日终投入比例为 `w_t`，首日前净值为投资计划中的模拟起始资金。倍率 `m` 分别取 1、2、3；假设年化融资利率 `c` 默认 8%，可在页面改为 0% 至 30%。估算借款比例为 `b_t = max(0, m * w_t - 1)`；只有放大后的持仓超过账户净值时才计息。情景按每个有记录的交易日计算：

`V_t = V_(t-1) * (1 + m * r_t - b_t * c / 252)`

若净值小于等于零，情景记录归零及可能的负债缺口，之后不恢复。假设维持担保比例默认 30%，可调整；若估算净值与放大持仓的比例低于该线，按当天收盘估值转为现金，后续不再交易。日线无法还原真实盘中强平价格，所以这是偏乐观的警戒情景。1x 路径等于基础组合净值，基础组合已有的模拟成交费用不会再次扣除。页面展示逐日净值、累计收益、期末资产、最大回撤、累计估算利息、借款峰值和警戒/归零日期。

这里的利率和维持担保比例均是数学敏感性假设，不是实际券商条款。模型仅按基础组合的日终仓位估算借款，没有重新生成 2x/3x 的实际订单；额外调仓成本、产品费率、跟踪误差、借贷资格、盘中保证金变化和可成交的强平价格均未知。估算利息只是现金流近似，也不能直接与最终收益差做简单加减。因此不能称作融资融券或杠杆 ETF 的可交易回测；在真实市场中损失可能更大。每日重置的倍数在多年区间也不会简单等于区间收益乘以倍率，参见 [SEC 的投资者说明](https://www.investor.gov/introduction-investing/general-resources/news-alerts/alerts-bulletins/investor-alerts/sec)。

## 若以后接入真实杠杆

先确定具体工具，而不是直接把普通 ETF 的下单数量乘二或乘三。需要和券商核实可交易产品、融资融券或衍生品权限、适当性、程序化交易报告及真实费用；按实际工具重新建模保证金与强平、行情和成交限制。连接账户后先只读核对资金、持仓、未完成订单和可用额度，再独立设置实盘限额、人工确认首单、订单幂等记录及紧急停止。上述步骤未完成前，真实杠杆下单保持关闭。
