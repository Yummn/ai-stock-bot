# Investor Workflow UI

## Ownership

- Overview owns the project paper account, starting capital, automatic updates and archive.
- Plan owns independent profile strategies, execution and risk settings. Previewing a profile does not activate it. Saving explicitly activates only the selected profile.
- Validation owns its historical interval. A changed interval is a pending test preference, not an unsaved strategy. Each result carries its frozen plan identity and interval. Displayed results never describe an unsaved draft.
- Independent tracking remains a separate frozen observation account, under validation.
- Research owns model comparisons, parameter searches and historical combination studies. Import remains draft-only.
- Broker separates live read-only data from broker simulation tests. No new order capabilities are added.

## State and Safety

Shared preference writes use the existing optimistic revision endpoint and the active saved profile, never the previewed profile. Unsaved strategy buffers are preserved. Account starting capital remains locked after simulation starts. Remote changes produce a visible conflict warning. Long-running jobs stay visible even when newer completed jobs exceed the recent-history limit.

The primary screen shows one workflow at a time. Presets show their summary; detailed settings and historical diagnostics are secondary. Views and their chart code are loaded on demand, and non-overview entry does not fetch market charts.

## Verification

Use isolated stores or intercept all browser writes. Never reset production accounts to test the UI. Check saved/draft transitions, per-profile persistence, year-only changes, stale and failed evidence reads, broker isolation, keyboard dismissal, mobile overflow and chart rendering. Strategy engines and default parameters are unchanged.
