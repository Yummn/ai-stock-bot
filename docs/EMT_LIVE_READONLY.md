# EMT 实盘只读接入

当前只有东方财富 EMT/EMQ **测试**账号，尚未取得真实资金账户、EMT 实盘服务器和白名单确认。因此真实账户仍显示“未接入”，不会尝试连接或下单。

## 需要向券商确认

1. 自己名下的真实证券资金账号，以及该账号能否使用 EMT 实盘 API。
2. EMT 实盘交易服务器的 IPv4 地址和端口；不要沿用测试地址。
3. 本机公网出口 IP 是否已加入该账号的 API 白名单；家庭网络 IP 变化后可能需要重新确认。
4. 程序化交易报告、协议和交易权限是否已按券商要求办理。

资料齐全后，在本机 `%LOCALAPPDATA%\AiStock\emt-live-readonly.json` 保存以下 JSON。此文件不在 Git 仓库里，**不得包含密码**：

```json
{
  "environment": "live_readonly",
  "broker_approved": true,
  "account": "券商确认的真实资金账号",
  "host": "券商确认的实盘服务器IPv4",
  "port": 12345
}
```

`broker_approved` 只是本机记录，不能替代券商正式批准。程序会拒绝已知测试账号、测试服务器、本机地址和无效端口。然后仅在电脑本机 `http://127.0.0.1:8771/#live` 点击“只读连接真实账户”，查询资金、持仓和未完成订单。查询结果只在当前页面显示，不保存到项目模拟账户或数据库；关闭或刷新页面后需重新查询。

东方财富[EMT API 常见问题](https://emt.18.cn/api/help/md_input_2EMTAPI__FAQ.html)说明实盘账户需要绑定白名单 IP，当前 API 登录由 IP 白名单控制，不校验密码字段。本项目只读连接传空密码，不提供实盘下单或撤单接口。若券商实际要求不同，请先停用并核对，不要把交易密码写进此配置。
