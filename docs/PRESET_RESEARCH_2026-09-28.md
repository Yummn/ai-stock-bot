# 默认基线与弱项参数研究

## 已生效

- 已将原启用方案版本 7 的全部参数保存为独立默认基线，包括五模型四档、本地、AI、风控、标的与标签。
- 恢复默认从数据库读取，普通保存和调优不覆盖默认。支持版本冲突校验，远程只读用户不能覆盖默认。
- “数据与维护”显示基线保存日期，并提供重新设置默认的入口。
- 当前启用方案版本为 8；唯一差异是 `cnn / balanced / allow_add: false → true`。
- 当前选择仍为 CNN 激进，未替用户切换风格；模拟账户、金额、份数、仓位、止损止盈限制均未改动。

## 研究范围与结果

查阅全部二十档已有证据，优先复核六组：RF 自定义、HGB 自定义、XGBoost 均衡、MLP 均衡、CNN 均衡和保守。

共完成 102 次参数/区间评价、338 次年度模拟。所有比较使用本轮冻结行情，训练只使用测试前的数据，保持费用和次日开盘成交口径。

先测试模型容量与双向买卖阈值，再检查预测周期、训练窗口、样本场景、分类目标和短序列窗口，最后做允许加仓的对照。没有因为结果不理想而放宽验收门槛。

唯一采用的改动：CNN 均衡允许加仓，仍受原资金和仓位上限约束。

| 指标 | 原参数 | 新参数 |
|---|---:|---:|
| 2021–2024 年度收益算术平均 | 1.31% | 2.23% |
| 2025 收益 | 0.89% | 1.12% |
| 2021–2024 最差最大回撤 | -1.73% | -2.82% |

这不是无风险改善：收益提高，部分年份的回撤也增加。该候选通过既定门槛和双倍费用、随机种子 43 的联合压力检查。其他五组未通过全部条件，保留原参数。

## 主要发现

1. 低收益不全是模型没学好。MLP、CNN 某些档位平均仓位只有几个百分点；保守档空仓也可能是防御目标的结果。
2. HGB 自定义成交较密集；延长持有在部分年份有效，但并未稳定通过后段和压力检查。
3. 更多训练历史、更复杂模型、五分类都不保证更好。本轮不少此类候选退步。
4. 单笔金额和份数限制共同生效；1 元标的最多买 2500 份，一笔约 2500 元，不是必然用满 1 万元。禁止重复加仓进一步限制参与度。放开加仓也会放大不利年份亏损，不能全档一刀切。
5. 当前二分类标签为未来收盘涨幅超过 0.1%，不是从次日开盘起算、扣费后的交易净收益。未来改进训练目标值得单独验证，本轮没有改变标签定义。

## 验证与限制

- 66 项测试通过；前端类型检查和构建通过。
- 浏览器验证默认恢复：CNN 激进草稿买入门槛从 0.75 恢复到保存的 0.53，而非早期内置值；未保存该临时草稿。
- 已复算全部已完成结果的曲线指标、年度边界、评分、标的数量、行情指纹和零规则回退；默认基线与账户逐项一致。
- 神经网络计算中曾出现 Tensor TypeError 和 Windows `0xC0000005`。研究脚本改为逐年进程隔离，失败重试后完成结果检查；这不证明原生库问题已根治，也不代表网页长期自动学习经过了稳定性验收。
- 2021–2025 都曾被研究。2025 不参与本轮候选排名，但多轮验收仍可能适应这些历史数据，不能宣称全新样本外表现或未来盈利。
